# Assistant Avatars

This directory contains the avatar images for each assistant.

## Required Files

Place the following image files in this directory:

- `guillote.png` - Avatar for Guillote assistant
- `kela.png` - Avatar for Kela assistant (Periodista Deportiva)
- `pela.png` - Avatar for Pela assistant
- `chori.png` - Avatar for Chori assistant
- `marta.png` - Avatar for Marta assistant

## Image Requirements

- Format: PNG (recommended) or JPG
- Recommended size: 200x200 pixels or larger (square format)
- The images will be displayed as circular avatars in the UI

## Source

These images should be copied from the `asistentes-landing` repository:
https://github.com/mabrutsky10/asistentes-landing.git

Look for the assistant avatar images in the original repository and copy them to this directory with the exact filenames listed above.
